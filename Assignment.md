# MongoDB-CRUD-Projekt

## Zeitraum

- Bis 07.10.

## Anforderungen

- Anbindung einer MongoDB
- Erstellen bzw. Generieren einer Beispieldatenbank
- GUI, ueber die auf die Datenbank zugegriffen wird (CRUD)
  - Beispiel: Eingeben von Kundendaten
  - Beispiel: Auslesen von Daten
  - Weitere CRUD-Funktionen: Erstellen, Lesen, Aktualisieren, Loeschen
- Moegliche GUI-Frameworks:
  - Streamlit
  - CustomTkinter
  - Tkinter
  - PyQt
  - PySide
- Kurze Skizze der Projektidee (heute)
- Dokumentation (mehr Informationen in VP)

## Ideen

- Shopsystem
- Benutzerverwaltung
- Kundenverwaltung
- Logdaten auswerten und anzeigen
- Smarthome-Messwerte eingeben und anzeigen
